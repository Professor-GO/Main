# Project context

- This project is for a hackathon.
- The concept is a Pokémon-inspired university game: players recruit professors through a token-based gacha process and battle with them. Token generation is out of scope for now.
- The current app uses a vanilla HTML/CSS/JavaScript frontend and Node.js 24 backend with SQLite accounts. Run it with `npm start`; run account integration tests with `npm test`.
